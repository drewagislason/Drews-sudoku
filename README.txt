VIKING SUDOKU  (ᛋᚢᛞᛟᚲᚢ)
======================
Open: double-click index.html (no web server needed). To host online, upload
the whole viking_sudoku folder (index.html, style.css, sudoku.js) to any static host.

How to play
- Each row, column, and 3x3 box must contain each rune exactly once:
  ᚠ ᚢ ᚦ ᚨ ᚱ ᚲ ᛝ ᛞ ᛟ  (stand-ins for 1-9)
- Click a rune in the bar under the grid, then click a square to place it.
- The blank "erase" tile clears a square.
- Shaded runes are given at the start and can't be changed.
- Conflicting runes are outlined in red. A full, correct grid wins automatically.
- Easy / Medium / Hard start a new puzzle (about 40-45 / 32-36 / 26-30 given runes).
  New Game starts a fresh puzzle at the current level. Every puzzle has one unique solution.

Runes need a Runic font: Windows ("Segoe UI Historic"), macOS, and most Linux systems
(Noto Sans Runic / DejaVu) include one.
